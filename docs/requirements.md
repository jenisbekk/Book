# Функционалдық талаптар

| № | Талап |
|---|-------|
| FR-1 | Жүйе кітапты қосуға, өзгертуге және жоюға мүмкіндік беруі керек (ISBN, атауы, авторы, жылы, данасы). |
| FR-2 | Жүйе оқырманды тіркеп, оның деректерін (билет нөмірі, аты-жөні, байланысы) сақтауы керек. |
| FR-3 | Жүйе кітаптарды атауы, авторы немесе ISBN бойынша іздеуі керек. |
| FR-4 | Жүйе кітап беру операциясын тіркеп, қайтару мерзімін (14 күн) белгілеуі керек. |
| FR-5 | Жүйе кітап қайтарылғанда оның қолда бар данасын арттыруы керек. |
| FR-6 | Жүйе мерзімі өткен кітаптардың тізімін көрсетуі керек. |
| FR-7 | Жүйе берілген және қайтарылған кітаптар тарихын сақтауы керек. |

## Пайдаланушылар

- Кітапханашы – кітаптар мен оқырмандарды басқарады, кітап береді және қабылдайды.
- Оқырман – кітаптарды іздейді, өз тарихын қарайды.
- Әкімші – жүйені және есептерді бақылайды.

## Бизнес-ережелер

- Қолда бар данасы жоқ кітапты беруге болмайды.
- Бір оқырман бір кітаптың екі данасын бір мезгілде ала алмайды.
- Қазір оқырманның қолында жүрген кітапты жоюға болмайды.
